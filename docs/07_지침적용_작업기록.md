## 적용 원문

사용자가 제공한 「바이브코딩 프롬프트 가이드」. 준비 → 설계 → README 커밋 → 기능별 구현 → 테스트·수정 → 검수 → 기록 보관 흐름을 적용합니다.

원문에 들어간 드론·기상·뉴스 기사·FastAPI/MySQL·유료 LLM 호출은 수업 예시입니다. 이번 요청에서는 해당 예시를 추가하지 않고 여행 안전 연락망의 실제 기술·기능으로 치환했습니다. 기존 프로그램을 다른 기술로 전면 교체하지 않습니다.

## 이번 문서 작업 변경점

1. 이전 순차 추가형 README를 실제 최신 V1.3 기준 8개 목차로 재정리했습니다.
2. 이전 README 전체는 docs/CHANGELOG.md에 역사 기록으로 보존했습니다.
3. 기획·기능정의/화면/DB/출처·환경/실행·검증/개발프롬프트를 분리했습니다.
4. 비밀값 없이 설정 이름만 있는 .dev.vars.example을 추가했습니다.
5. 현재 운영 사실: D1/R2, 물리 FK 없음, 현재 위치 최신 1건 보관, 문자·이메일 실발송·정기감시 미연결.
6. 기존 여행안심 UI와 기능 코드는 이번 문서 작업에서 변경하지 않았습니다.
