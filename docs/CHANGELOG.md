# 여행안심 V1

휴대전화 중심의 비공개 여행 기록 서비스입니다.

## 구현
- 소유자 로그인, 계정별 D1 저장 및 인증된 R2 사진 저장
- 여행 1건, 연락처 최대 10명, 최근 기록 100건
- 여행 일정/예정 경로, 안전 확인, 귀가 완료, 저장 후 홈 복귀
- 화면이 열린 동안 GPS 위치 지도 표시 및 약 1분 간격 저장
- 여행자/실종 추정 지역 사진 등록: JPEG·PNG·WebP, 각 5MB
- 가족·친구 및 한국 집 근처 경찰/현지 경찰/공관 연락처 등록
- 전화, 문자 작성, 텍스트 공유, 사진 포함 인쇄/PDF 저장
- QR 접속 후 본인 로그인. QR은 가입/접근 권한을 자동 부여하지 않습니다.

## 미완료
24시간 기준시각은 표시하지만 서버 감시 스케줄러와 자동 발송은 연결되지 않았습니다. 경찰/공관 자동 접수 및 관할 자동 선정도 미구현입니다. 공식 수신 경로/협약 및 발송서비스 설정이 필요합니다. SOS 기록은 기관 접수를 뜻하지 않습니다.

잠금·종료 중 위치 갱신은 지원하지 않습니다. 위치는 마지막 저장시각과 정확도를 표시합니다. 주변 경찰서 링크는 지도 검색이며 관할/최단거리를 검증하지 않습니다.

## 사용
여행 등록 → 연락망 등록 → 위치 켜기 및 안전 확인 → 필요시 신고자료 출력 → 귀가 완료. 사용 안내에서 전체 자료를 삭제할 수 있습니다. 자료는 직접 삭제할 때까지 보관됩니다.

## 검증
내부 브라우저에서 여행 저장, 메인 복귀, 안전 확인 저장을 확인했습니다. 타입 검사와 프로덕션 빌드를 확인합니다. 실제 휴대전화에서 GPS·문자·전화·PDF 저장 확인은 별도 필요합니다.

## 개발
Sites Vinext / React / TypeScript / D1 / R2. `pnpm install`, `pnpm db:generate`, `pnpm build`. 호스팅 인증은 Sites가 담당합니다. 이 버전에는 MySQL/PostgreSQL이 포함되지 않습니다.

## V1.1 변경 (2026-10-20)
- 연락처 이름·전화번호·이메일·수신동의가 필수입니다. 화면과 서버에서 모두 검사합니다.
- 기존 연락처 수정, 중복 전화/이메일 방지, 누락 이메일 보완 안내.
- 가족/친구 관계만 24시간 알림 대상으로 선택합니다. 국내 휴대전화 LMS 및 이메일 어댑터를 추가했습니다.
- SOLAPI 공식 send-many/detail 및 HMAC-SHA256 인증, Resend emails API를 사용합니다.
- 알림 사용 요청 및 중지, 사진 포함 이메일 자료, 접수/거절/결과불명 기록.
- 같은 안전 확인 주기·수신자·채널을 해시 키로 고유 등록하여 중복 요청을 막습니다. 요청 중 프로세스 종료나 통신 결과불명은 자동 재발송하지 않으며 업체 내역 확인이 필요합니다. 업체 접수는 수신 완료가 아닙니다.
- /mcp는 인증된 본인의 여행만 스캔하며 다른 사용자의 자료를 읽지 않습니다.
- 미래 출발 여행은 한국시간 출발일 이전에 알리지 않습니다. 등록일과 출발일 중 늦은 시각 이후 안전 확인 기준으로 24시간을 계산합니다.

### 실제 자동화 연결에 필요한 설정
문자: SOLAPI_API_KEY, SOLAPI_API_SECRET, SOLAPI_FROM (등록·인증한 국내 발신번호 및 이용 잔액).
이메일: RESEND_API_KEY, ALERT_EMAIL_FROM (인증된 발신 도메인/주소).
Sites 보안 환경변수로 설정하고 배포해야 합니다. 키를 소스나 채팅에 기록하지 마세요.
정기감시는 게시된 Site MCP 연결의 check_due_safety_alerts를 호출하는 작업을 생성하고 무인 실행 권한 및 읽기 결과를 검증해야 합니다. 완료한 뒤에만 ALERT_SCHEDULER_READY=true로 설정합니다. 현재 발송 설정 및 스케줄러는 미연결 상태입니다.
따라서 아직 앱을 닫아도 자동 발송되는 운영 상태가 아닙니다. 기본 알림 설정은 꺼짐이며 연락처의 동의도 필요합니다.
사진은 이메일 첨부로만 포함되며 문자는 텍스트·마지막 위치 링크입니다. 경찰/공관에는 발송하지 않습니다.

### 검증 추가
`node --experimental-strip-types tests/alert-rules.test.ts`: 필수항목, 동의, 24시간 경계, 안전 확인/귀가/수동 중지, 미래 여행, 국내 번호 변환을 확인합니다.
실제 외부 발송은 계정 미연결로 미검증입니다.

## V1.2 최신 휴대전화 자료 업로드 (2026-10-20)
- 사진 선택/촬영 직후 업로드, 여행자 및 지역 사진 각각 최근 업로드 시각 표시.
- 사진 전체 라이브러리/주소록은 읽지 않습니다. 사용자가 선택한 사진만 업로드합니다. HEIC는 현재 지원하지 않으며 JPEG·PNG·WebP 각 5MB 제한입니다.
- 계정·기기별 위치 자동 업로드 선택을 기억하며, 재접속 시 기존 위치 권한이 granted일 때만 자동 재개합니다. 귀가 완료/자료 삭제 시 자동 위치를 끄고 해당 기기의 설정을 지웁니다.
- 위치 측정시각과 서버 업로드시각 분리. 이전 측정값이 더 최신 위치를 덮어쓰지 않게 합니다. 위치가 바뀌어도 안전 확인 24시간 기준은 초기화하지 않습니다.
- 네트워크 재연결/화면 복귀 시 서버의 최신 정보와 사진 메타데이터를 다시 읽습니다. 미업로드 자료의 오프라인 자동 재전송은 미지원입니다.
- 자동 이메일 요청 직전에 최신 서버 정보를 읽고 최신 사진 2종 및 latest-travel-report.json을 첨부합니다. 위치 확인시각/오차/업로드시각과 30분 이상 지난 위치 여부를 포함합니다.
- 문자에는 마지막 저장 위치의 확인시각 및 지도 링크를 포함합니다. 휴대전화 잠금/종료 중 새 위치나 새 사진을 서버에서 가져올 수는 없습니다.
- 발송 계정과 무인 정기감시는 여전히 미연결입니다. 아직 실제 자동 발송은 활성화되지 않았습니다.

## V1.3 여행 중 2시간 위치 저장 (2026-10-20)
- 현재 위치 지도 갱신과 서버 저장 간격을 분리했습니다. 자동 위치 사용 중 지도는 GPS 수신 시 갱신하고 서버는 2시간 간격으로 저장합니다.
- 등록된 여행 기간(한국시간 출발일 00:00~귀가일 종료) 중 첫 자동 위치는 즉시 저장합니다. 이후 서버에 기록한 lastAutoLocationAt에서 2시간 경과한 경우만 저장합니다.
- 새로고침/재접속/중복 요청도 서버에서 간격을 확인합니다. 수동 저장은 자동 저장 예정시간을 변경하지 않습니다.
- 움직이지 않는 경우도 고려해 화면이 열린 동안 1분마다 저장시각 도래 여부를 점검하고 필요할 때 새 GPS 좌표를 요청합니다. 실제 기록시각은 GPS/네트워크/브라우저 상태에 따라 지연될 수 있습니다.
- 여행 기간 외 및 귀가 완료 후 자동 저장을 중지합니다. 자동 저장은 안전 확인 24시간 알림 시각을 갱신하지 않습니다.
- 다음 자동 저장 예정시각을 표시하고 자료의 위치 상태는 최근 2시간 기준으로 표시합니다.
- 웹 화면 종료/잠금 중 정확한 2시간 저장은 보장되지 않습니다. 실제 iOS/Android 백그라운드 추적은 별도 네이티브 앱 구현이 필요합니다.
- tests/location-rules.test.ts: 첫 저장, 2시간 직전/직후, 재접속 간격 유지, 여행 기간/귀가 중지, 수동 저장 분리를 확인합니다.
