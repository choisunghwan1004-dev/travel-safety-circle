# 여행안심 · OpenAI 적용 계획

검토일: 2026-10-20. 상태: 모델·기능 선정 완료, 실제 API 연동·호출·평가 미실행.

## 독립 시스템 범위

여행안심은 점심 추천·여행코스 추천·지역 뉴스 서비스와 분리된 독립 프로젝트입니다. 각 사용자는 본인 로그인 계정의 여행·연락망·사진·위치·발송 기록만 조회하고 수정합니다. 현재는 하나의 호스팅 서비스에서 계정별로 논리 분리하며, 사용자마다 별도 물리 DB·서버를 자동 생성하는 기능은 없습니다. Sites 인증을 사용하므로 현재 소스는 인증 환경을 교체하지 않고 임의 서버에서 완전히 독립 운영되는 버전이 아닙니다.

## OpenAI가 유용한 기능

| 기능 | 입력 | 출력 | 상태 |
|---|---|---|---|
| 신고 참고자료 정리 | 본인이 확인한 여행·위치·숙소·연락처 | 근거 항목을 연결한 짧은 요약 초안 | 적용 계획 |
| 한국어·일본어·영어 번역 | 전달할 원문과 대상 언어 | 원문과 병기한 번역 초안 | 적용 계획 |
| 누락 항목 안내 | 필수값 검사 결과·등록자료 | 추가 확인해야 할 내용 설명 | 적용 계획 |
| 안내문·표지판 텍스트 읽기 | 사용자가 별도로 선택·승인한 이미지 | 보이는 글자 추출·번역 | 후속 검토 |

실종 판단, 위험 등급 결정, 경찰 관할 선정, 2시간 위치 저장, 24시간 미응답 계산, 수신 동의, 실제 발송 여부는 모델이 결정하지 않습니다. 시간·동의·발송은 서버 규칙으로 처리합니다. 모델이 실패해도 원본 자료·고정 알림 문구를 사용할 수 있어야 합니다. 실종 판정이나 얼굴로 사람을 식별하는 기능을 추가하지 않습니다.

## 모델 선택

기본 시험 모델은 `gpt-6-luna`를 제안합니다. 짧고 범위가 정해진 요약·번역·구조화 출력에 비용을 낮춰 사용할 수 있다는 판단입니다. 공식 모델 목록은 비용 민감 작업에 GPT-6 Luna, 복잡한 작업의 품질·비용 균형에 GPT-6.1 Sol을 안내합니다. Luna는 이미지 입력과 텍스트 출력, Structured Outputs를 지원합니다. 실제 여행안심 한국어·일본어 자료에 대한 우수성이 검증됐다는 의미는 아닙니다.

긴 자료의 복잡한 대조가 필요하고 Luna 평가에서 미흡하면 `gpt-6.1-sol`을 별도로 평가합니다. 실패 시 임의로 비싼 모델로 자동 전환하지 않습니다.

공식 기본 텍스트 단가(2026-10-20 확인, 100만 토큰당):
- GPT-6 Luna: 입력 $0.10 / 출력 $0.50.
- GPT-6.1 Sol: 입력 $2 / 출력 $10.
도구·이미지·세금·환율·처리등급은 별도일 수 있습니다. 고정 월요금 또는 실제 운영 비용 측정치가 아닙니다.

공식 근거:
- https://developers.openai.com/api/docs/models
- https://developers.openai.com/api/docs/models/gpt-6-luna
- https://developers.openai.com/api/docs/models/gpt-6.1-sol

## 연동 조건과 검증

1. 본인이 선택한 자료만 전송하고, 보내기 전 항목과 외부 전송 여부를 화면에서 확인합니다.
2. OPENAI_API_KEY는 서버 보안 설정에만 저장합니다. 브라우저·GitHub·노션·채팅에 넣지 않습니다.
3. API는 Responses API와 구조화 출력을 사용하도록 설계합니다. 원본 시각·숫자·좌표·연락처는 서버가 그대로 유지하고, AI가 만든 문장과 섞어 원본 사실로 저장하지 않습니다.
4. 요약·번역은 사람이 원문과 대조한 뒤 공유합니다. 누락은 ‘미등록’으로 표시하고 내용을 지어내지 않습니다.
5. 모델별 테스트에서 원문 수치·날짜·연락처 보존, 미등록 표시, 한국어/일본어/영어 품질, 실패 시 원본 표시를 확인합니다.
6. 현재 API 키 연결·실제 호출·실사용 품질 검증은 모두 미완료입니다. 사용 가능 계정·모델 권한도 미확인입니다.
