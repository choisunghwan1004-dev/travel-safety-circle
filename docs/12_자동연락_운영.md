# V1.7 · 24시간 미응답 자동 연락

## 기준과 자료

- 기본 기준은 여행 출발일(한국시간)과 마지막 **본인 안전 확인** 중 늦은 시각에서 24시간입니다. 다음 확인 예정시간이나 GPS 업로드는 이 기준을 초기화하지 않습니다.
- 본인이 자동 알림 사용 요청을 켜고, 이름·전화번호·이메일·수신 동의를 갖춘 가족 또는 친구에게만 보냅니다. 귀가 완료·사용 중지·안전 확인·연락처 삭제·동의 철회 시 다음 발송을 중지합니다.
- ‘실종 확정’ 대신 ‘24시간 미응답 · 안전 확인 필요’로 안내합니다. 경찰·대사관 자동 접수는 없습니다.
- 이메일: 최신 서버 여행정보, 항공편·좌석, 등록한 기관 연락처, 마지막 위치와 지도 링크, 위치/자료/사진 시각, 여행자·지역 사진, 읽을 수 있는 TXT와 JSON 첨부.
- 문자: 한국 휴대전화에 요약·여행자 연락처·마지막 위치 지도 링크. 사진은 이메일에 첨부합니다.
- 휴대전화 사진첩·연락처 전체를 임의 수집하지 않습니다. 선택하여 업로드한 자료와 허용한 GPS만 사용합니다. 웹 종료·잠금 중 새 GPS 확보는 보장하지 않습니다.

## 무료 기본 서비스와 업체 연결

홈의 ‘자동 연락 연결 · 문자/이메일 설정’에서 본인의 Resend 또는 SOLAPI 설정을 등록합니다. 이메일 한 채널만으로도 작동합니다. OpenAI 키는 필요하지 않습니다.

- Resend: 본인 API 키, 인증한 발신 도메인의 이메일, 업체 수신자 제한·한도 확인.
- SOLAPI: 본인 API 키·비밀키, 인증한 국내 발신번호, 발송 잔액.
- 업체 비용은 연결한 계정에 적용합니다. 키 저장은 형식 검사이며 실제 인증·잔액·수신 성공 검증은 아닙니다.
- 계정별 키는 기존 USER_KEY_ENCRYPTION_SECRET으로 AES-GCM 암호화합니다. AAD에 별도의 notifications 범위를 사용합니다. 화면·PDF·공유·GitHub에 비밀을 내보내지 않습니다.
- 서버에 공용 발송 설정이 있는 경우 개인 설정이 없는 계정에만 기존 서버 설정을 적용합니다. 개인 설정 등록 후에는 개인 설정만 사용합니다.
- 채널 해제는 해당 채널만 비활성화합니다. 내 자료 전체 삭제 시 개인 발송 키와 점검 기록도 삭제합니다. 업체에서 키 자체를 폐기하려면 대시보드에서 직접 폐기합니다.

## 정기 실행

사이트 소유자의 연결된 여행안심 도구를 매시간 호출하는 Sites 정기 작업을 생성했습니다. 한국시간 기준 설정이며 24시간 경과 후 다음 점검에서 처리합니다. 지연·장애로 정확히 24시간 도착을 보장하지 않습니다.

작업: `Automation_5794856a967481919df7c041cd0f2ca5`

점검은 로그인한 본인 계정만 처리합니다. 이 작업이 모든 가입자의 자료를 처리하는 전역 작업은 아닙니다. 다른 가입자는 본인 여행안심 플러그인과 별도 정기 작업을 연결해야 합니다. 배포형 전체 사용자 운영에는 별도 서버 작업 운영과 모니터링이 필요합니다.

`alert_monitors`는 계정별 마지막 점검 시각·결과만 저장합니다. 화면의 ‘3시간 이내 실행’은 최근 도구 호출 기록이며 다음 실행 보장이 아닙니다. 브라우저를 열어두는 타이머로 정기 작업을 대체하지 않습니다.

## 중복과 실패

계정·안전 확인 주기·채널·수신자를 해시한 발송 ID를 D1 기본키로 선점합니다. 동시 호출도 같은 수신자/주기에 두 번 요청하지 않습니다. 재조회하여 알림 중지·안전 확인·귀가·수신 동의 변경을 확인합니다. 이미 전송 중인 요청은 취소하지 못할 수 있습니다.

업체 접수는 도착이 아닙니다. 통신 결과 불명·요청 중·거절은 발송내역에 남기고 자동 재전송하지 않습니다. 중복을 피하는 정책이므로 실제 누락 가능성은 운영자가 업체 발송내역에서 확인해야 합니다. 키가 없는 경우에는 발송 선점 기록을 만들지 않아 설정 후 다음 점검에서 처리할 수 있습니다.

## 검증

- 24시간 직전/정각, 출발 전, GPS가 안전 확인을 대체하지 않음, 알림 중지·귀가·동의 철회·관계/수신자 변경.
- 이메일 단독 발송, 사진 2개와 TXT/JSON 첨부, 동시 점검 중복 선점, 재호출 무발송, 설정 없음, 통신 결과 불명 무재전송: 가짜 업체 응답/DB로 통합 검증.
- 암호화/계정 격리, 입력 형식·헤더 줄바꿈 차단, 기존 GPS/자동 입력, TypeScript, SQL 마이그레이션 및 빌드 검사.
- 임시 QA 화면에서 이메일/문자 메뉴 전환 및 키·비밀키 입력 표시/로그인 필요 차단을 확인하고 QA 경로는 삭제했습니다.
- 실제 발송 키가 없어 문자·이메일 도착과 실제 단말 수신은 미검증입니다. 정기 작업 저장 자체는 최초 실행 성공 증거가 아닙니다.

공식 API 참고: https://resend.com/docs/api-reference/emails/send-email · https://solapi.com/developers/api/messages · https://solapi.com/developers/api/authentication-api-key

## V1.7.1 변경

새 여행·가족/친구 연락처 저장 시 기본 자동 연락을 설정하고, 업체 발송 키 저장 시에도 등록 조건을 확인해 자동 활성화합니다. 본인이 직접 중지한 설정은 alertPreference=off로 보존합니다. 이전 버전의 명시적 자동 알림 중지 이벤트도 유지합니다. 기존 여행의 아무 설정도 저장하지 않은 자료를 임의로 변경하지 않습니다. 현재 계정별 설정에 SOLAPI/Resend 키가 없으면 발송하지 않으며 서버 공용 설정도 현재 없습니다. 최근 점검은 발송 성공을 뜻하지 않습니다.

홈의 기준 점검 버튼은 실제 24시간 미응답·활성화·동의 조건이 갖춰졌다면 발송을 요청합니다. 단순 모의 테스트 버튼이 아닙니다. 연락망에서 업체 접수·거절·확인 필요를 확인합니다.

휴대전화 GPS는 여행 등록과 독립적으로 한 번 확인할 수 있습니다. 여행 기간 중 2시간 저장 규칙과 브라우저 잠금/종료 제한은 유지합니다. 한국112/일본110은 사용자가 현재 통화 국가를 확인한 뒤 전화 앱을 실행합니다. 집 근처 경찰서 번호가 없다고 해당 경찰서 번호인 것처럼 112를 저장하지 않습니다.

공식 번호 근거: https://www.police.go.kr/www/agency/intro/intro0601.jsp · https://www.npa.go.jp/goiken_index.html

## V1.8 현재 운영 기준

기존 문서의 가족/친구 한정·10명 제한은 폐지했습니다. 이름·전화번호·이메일·수신 동의를 갖춘 서비스 등록 지인 전원이 대상입니다. 연락망 공유 동의를 받은 연락처만 등록합니다. 등록된 연락처 전원을 자동 TXT/JSON 자료에 넣습니다. 실종 여부를 자동 확정하지 않고 기존 24시간 미응답 조건으로 안전 확인 필요 자료를 전달합니다.

대량 처리: 최근 주기의 수신자/채널 발송 ID를 확인하고 이미 처리한 대상은 생략합니다. 50건 또는 약45초 이후 남은 대상은 pending으로 반환하고 다음 도구 호출에서 이어갑니다. pending은 발송 성공이 아니며 꺼진 정기 작업에서는 자동 후속 처리가 없습니다. 이메일은 각 요청 전700ms 간격을 두지만 업체 요금·한도·실제 도착은 보장하지 않습니다. 국내 휴대전화가 아닌 SMS는 지원번호 확인 필요로 남기고 이메일은 별도로 처리합니다. 통신 결과 불명·업체 거절은 기존 정책에 따라 자동 재전송하지 않습니다.

GPS 지역: 원 좌표가 있으면 마지막 저장 지역을 휴대전화 GPS 좌표로 보완하고 획득 시각을 함께 보관합니다. 동일 획득 시각에 확인한 지역명은 유지하되 이전 GPS의 지역명을 현재 위치로 표시하지 않습니다. 여행 저장 전 GPS를 요청하고 실패하면 위치 없이 일정만 저장을 명시적으로 선택할 수 있습니다. 배경에서 반복 역지오코딩은 추가하지 않았습니다.

운영 확인: 발송 키 미등록, 소유자 정기 작업 일시 중지 상태를 그대로 유지합니다. 설정 완료와 정기 작업 재개 전에는 자동 연락이 작동하지 않습니다. 테스트는 가짜 업체/DB에서 61명 전원·이어서 처리·중복 없음·연락처 자료 자동 포함을 확인한 것이며 실제 연락망에 메시지를 보내지 않았습니다.
