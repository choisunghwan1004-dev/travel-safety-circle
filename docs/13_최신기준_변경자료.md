# 여행안심 V1.8.1 · 지침서 적용 및 최신 변경 자료

기준일: 2026-10-21. 실제 소스·스키마와 대조한 통합 기준입니다. 이전 버전 문서·Notion의 대기 기록은 이 문서의 현재 상태로 대체하여 해석합니다. 이번 변경은 문서 정리이며 앱 코드·UI·비밀 설정·정기 작업은 변경하지 않습니다.

## 1. 프로젝트 소개와 적용 지침

개인이 국내외 여행의 일정·GPS·사진·연락망을 등록하고, 24시간 본인 안전 확인이 없으면 동의한 지인에게 최신 서버 자료를 전달하도록 준비하는 무료 예방 서비스입니다. 미응답을 실종으로 확정하거나 경찰·대사관에 자동 신고하지 않습니다. 업체 비용은 연결한 본인 계정에 적용됩니다.

사용자의 바이브코딩 프롬프트 가이드에 따라 준비 → 설계 → README → 기능별 구현 → 검증 → 기록 보관을 적용합니다. 예시 업종·뉴스 생성·샘플 운영 자료를 추가하지 않고 기존 React/Vinext/D1/R2 구현을 유지합니다.

GPS 저장은 안전 확인을 대신하지 않습니다. 출발 전·귀가 완료·알림 중지·동의 철회는 발송 대상에서 제외합니다. 실제 GPS가 없으면 위치를 지어내지 않고 위치 없음으로 전달합니다. 휴대전화 주소록·사진첩을 자동 수집하지 않습니다.

## 3. 화면과 이용 흐름

로그인/QR 접속 → 소개 배너와 준비 상태 → 여행·지인 연락망 등록 → 위치 권한 및 선택 사진 업로드 → 본인 발송 설정 → 자동 알림 요청·정기 점검 → 여행 중 안전 확인 → 귀가 완료.

홈에는 여행·동의 연락망·발송 설정·최근 점검·GPS의 다섯 준비 항목이 있습니다. 지도 검색에는 외부 전송 동의가 필요하고 경찰서 후보·번호는 확인 후 선택합니다. AI 설정과 문자/이메일 설정은 서로 다른 키를 사용합니다. 저장 후 홈 복귀 및 기존 하단 메뉴를 유지합니다.

## 4. DB·ERD·PK/FK

실제 D1 스키마는 7개 테이블이며 전체 컬럼은 [DB 설계](03_DB_ERD.md)를 따릅니다. 연락처·여행·위치는 journeys.data JSON이고 별도 정규화 SQL 테이블이나 물리 FK는 없습니다. owner는 인증 계정과 논리적으로 연결됩니다. 사진은 R2의 계정별 객체이며 최신 위치는 1건만 보관합니다. 이전 마이그레이션을 수정하지 않고 0000~0005 순서로 적용합니다.

## 5. 데이터 출처·환경·비용

본인 입력, 허용한 Geolocation, 선택 사진, 공개 지도(Nominatim/Overpass), 본인 동의하에 OpenAI로 전송한 자료를 사용합니다. 경찰시설 검색은 대략적 좌표 또는 시구동·24시간 해시 캐시·호출 제한을 적용합니다. 공개 검색 결과는 실제 관할·최인접·전화 정확성을 보장하지 않습니다.

Node 22.13 이상 / pnpm11.25 / React19.2.6 / TypeScript5.9.3 / Vinext1.0.0-beta.5 / D1·R2를 사용합니다. 버전 근거는 package.json과 lockfile입니다. 기본 수동 등록·GPS·자료 작성은 OpenAI 키 없이 가능합니다. AI·SMS·이메일은 각 본인 업체 계정의 사용료·인증·잔액·한도에 따릅니다. 키 등록 성공은 업체 인증·실수신 성공이 아닙니다.

## 6. 실행·운영 준비

로컬 설치·빌드·최초 DB의 0000~0005 적용 절차는 [실행·검증](05_실행_검증.md)을 따릅니다. 비밀값은 GitHub·Notion·채팅에 기록하지 않습니다. 본인 AI/발송 키는 화면에서 등록하고 서버 마스터키와 분리합니다. OpenAI에 공용 키 대체 호출은 없습니다.

현재 발송 키는 미등록이고 소유자 매시간 정기 작업은 일시 중지 상태입니다. 이번 문서 정리에서 Sites의 작업 is_enabled=false를 재확인했습니다. 최근 3시간 점검 표시는 호출 기록이며 정기 작업 활성·실제 도착을 뜻하지 않습니다. 다른 가입자는 본인 정기 작업을 연결해야 하며 전체 가입자 전역 감시는 구현하지 않았습니다.

운영 전 본인 발송 설정 → 명시적으로 지정한 시험 수신처로 업체 접수와 실제 도착 각각 확인 → 정기 작업 재개 및 무인 호출 확인이 필요합니다. 문서 정리만으로 작업을 재개하거나 메시지를 보내지 않습니다.

## 7. 검증과 제한

기존 V1.8 검증은 가짜 업체/DB에서 혼합 관계 지인61명을 50+11로 이어 처리하고 중복 요청 없음, 자료에 전원 연락처 포함, 동의 없음 제외, 해외 SMS 지원번호 확인과 이메일 독립 처리를 확인했습니다. V1.8.1은 TypeScript·빌드 통과, 이미지 확인 완료이며 브라우저 연결/정책 오류로 배너의 실제 화면 검증은 미완료입니다.

재현 명령(외부 메시지 발송 없음):

```sh
node --experimental-strip-types tests/alert-rules.test.ts
node --experimental-strip-types tests/location-rules.test.ts
node --experimental-strip-types tests/assist-rules.test.ts
node --experimental-strip-types tests/trip-autofill.test.ts
node --experimental-strip-types tests/openai-report.test.ts
node --experimental-strip-types tests/key-crypto.test.ts
node --experimental-strip-types tests/search-location.test.ts
node --experimental-strip-types tests/notification-rules.test.ts
node --experimental-strip-types tests/safety-setup.test.ts
node --experimental-strip-types tests/last-area.test.ts
node tests/alert-dispatch.test.mjs
pnpm exec tsc --noEmit

```

실제 OpenAI 호출·iPhone/Android GPS·SMS/메일 도착·단말 QR/PDF는 미검증입니다. 잠금/종료 중 GPS는 웹에서 보장하지 않습니다. 미응답은 실종 확정이 아니고 업체 접수는 도착이 아닙니다. 결과 불명·거절은 자동 재전송하지 않으며, pending은 다음 점검이 있어야 이어집니다.
